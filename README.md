# CampusVision Smart Attendance

An AI-powered, multi-platform smart attendance management system.

## Quick Start
1. Ensure you have your `backend/.env` configured with your MongoDB URI.
2. Start the backend server: 
   ```bash
   cd backend
   python app.py
   ```
3. Open `frontend/index.html` in your browser for the Admin portal.
4. Open `frontend/student.html` for the Student portal.
5. **For Mobile Testing:** Run `npx localtunnel --port 5000 --local-host 127.0.0.1` and open the generated link on your phone.
